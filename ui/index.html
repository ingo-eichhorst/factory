        Infrastructure

        AI accounts are declared in the root config, never discovered: Factory opens no credential file, keychain or .env to draw this page. An account shows its name, vendor, kind and plan, and the agents that use it -- never a value. An API key's environment variable is shown by name only.

        Infrastructure is not available on this daemon: it was built before /api/infrastructure existed. Rebuild and restart the daemon to see the host, the daemon and the AI accounts here.

        Doctor

        Doctor compares the newest Factory build evidence with SBOM evidence read from the installed factory and factory-daemon binaries. Scanning runs in the factory scope's workflow, outside the daemon; this page only reads immutable attachments.

        Doctor is not available on this daemon: it was built before /api/doctor existed. Rebuild and restart the daemon to inspect the installed release.

        Backup

        A backup is the instance's own state: the database, copied consistently while the daemon runs, the configs, and the authored content nothing regenerates. Secrets are never read or copied, and scope source code is backed up by pushing each repository to its git remote, not here. A backup is only claimed once its manifest verifies.

        Backup is not available on this daemon: it was built before /api/backup existed. Rebuild and restart the daemon to see backups here.
